ⓘ Quick Guide — Adding a Domain
  • Parent domain = Leave "Parent" field empty. These are the 16 main categories shown on the landing page.
  • Child domain = Select a parent from the dropdown. These appear under the parent.
  • New assessment domain? Go to Assessment → Questions and map questions to this domain.
  • Jobs that should belong to this domain will need updating separately.
  • Image is optional. Only parent domains typically need one (shown on landing page).
  • Tip: Use the Upload CSV button on the domain list page to add multiple domains at once.
